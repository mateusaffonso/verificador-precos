Configurações

O token fica salvo só neste navegador e é usado para salvar sua lista de produtos e disparar verificações no seu repositório.

Como criar o token
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e selecione este repositório.
  3. Em Permissions → Repository: Contents: Read and write e Actions: Read and write.
  4. Gere e cole aqui. Use expiração curta (ex.: 60 dias).
